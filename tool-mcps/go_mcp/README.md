# go_mcp

Enrichment MCP — 9 tools backed by `mrbigr.core.go`.

## Tools

`run_go_enrichment`, `run_gsea_analysis`, `plot_go_enrichment`,
`plot_gsea_results`, `run_kegg_enrichment`, `get_enrichr_libraries`,
`extract_go_from_gtf`, `simplify_go_results`, `export_go_report`.

Standalone: `python tool-mcps/go_mcp/src/server.py`
Register:   `mrbigr install go_mcp`
