# peak_mcp

Peak & haplotype visualization MCP — 4 tools backed by
`mrbigr.core.peak`.

## Tools

`plot_qtl_boxplot`, `plot_grouped_boxplot`, `haplotype_test`,
`multi_trait_qtl_plot`.

Standalone: `python tool-mcps/peak_mcp/src/server.py`
Register:   `mrbigr install peak_mcp` (Claude default; add `--client codex` or `--client gemini`)
Export:     `mrbigr export-config peak_mcp --format mcpservers` (or `gemini` / `opencode`)
